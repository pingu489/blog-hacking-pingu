👹 Andrasd - Demonio de Integridad de Archivos Críticos

🚀 Andrasd es un demonio diseñado para vigilar archivos críticos de sistemas Linux y detectar cambios no autorizados. Su objetivo es proteger la integridad de archivos esenciales y alertarte si alguien intenta modificarlos.

💻 Qué archivos vigila

Actualmente monitoriza:

  • /etc/passwd 🧑‍💻 - Información de usuarios del sistema
  • /etc/shadow 🔒 - Hashes de contraseñas
  • /etc/sudoers ⚡ - Permisos de usuarios con privilegios

⚙️ Cómo funciona

1. Calcula un hash SHA256 de cada archivo crítico y lo guarda en un archivo seguro.

2. Compara periódicamente los hashes para detectar cambios.

3. Genera alertas en un log si se detecta algún cambio, manteniendo un registro completo.

🛡️ Beneficios

Es un mini Tripwire casero, ideal para aprender sobre ciberseguridad y mantener tus sistemas protegidos de modificaciones no autorizadas. Puede ampliarse para enviar alertas por Telegram o email, o convertirse en un servicio systemd para funcionar como un demonio completo.

📘 Manual de uso – andrasd

1. Instalación

Copiar el demonio a /usr/local/bin, dar permisos y verificar:

sudo cp andrasd.sh /usr/local/bin/andrasd
sudo chmod 755 /usr/local/bin/andrasd
andrasd --help   # Opcional para probar

2. Invocar a andrasd

Iniciar el demonio en segundo plano con privilegios de administrador:

sudo andrasd &

3. Verificación

Comprobar que el demonio está activo en el sistema:

ps aux | grep andrasd
htop           # También puedes usar htop para verlo

4. Monitorización

Revisar las alertas generadas por cambios en archivos críticos:

sudo tail -f /var/log/andrasd.log

5. Detener

Detener el demonio de forma manual si es necesario:

sudo pkill andrasd
